# مقدمة إلى PHP 7: البرامج النصية من واجهة الأوامر والخدمات الويب

📘 **الوصول إلى وثائق الدورة التدريبية:** [https://stahe.github.io/ar-php7-juillet-2019/](https://stahe.github.io/ar-php7-juillet-2019/)

---

يقدم هذا المشروع مجموعة من البرامج النصية من وحدة التحكم في PHP 7 التي توضح جوانب مختلفة من اللغة ونظامها البيئي.

## محتويات المستودع

تتناول الأمثلة المواضيع التالية:
- **هياكل اللغة**
- **الوصول إلى الملفات**
- **الوصول إلى قاعدة البيانات**
- **الوصول إلى الإنترنت**

## نهج الويب

يتم تناول برمجة الويب هنا من منظور **خدمات الويب**. في هذا السياق، نُعرّف "خدمة الويب" بأنها أي تطبيق ينتج نصًا بسيطًا (خادم بيانات)، على عكس خوادم صفحات الويب التي تولد مزيجًا من HTML و CSS و JavaScript.

### المفاهيم الأساسية التي يتم تناولها
يستكشف المشروع المفاهيم الأساسية للويب المستخدمة في البرمجة التقليدية:
- بروتوكول HTTP
- تنسيقات الاستجابة JSON أو XML
- إدارة الجلسات
- المصادقة
