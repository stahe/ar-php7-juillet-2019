    12. استخدام SGBD MySQL

    سنقوم الآن بكتابة نصوص برمجية PHP باستخدام قاعدة بيانات MySQL:

    في البنية المذكورة أعلاه، لا يتواصل البرنامج النصي PHP (1) مباشرةً مع SGBD (نظام إدارة قواعد البيانات) (3). بل يتواصل مع وسيط يُسمى برنامج تشغيل SGBD أو برنامج تشغيل SGBD. يوفر PHP واجهة قياسية لهذه برامج التشغيل، وهي واجهة PDO (كائنات بيانات PHP). يتم تنفيذ هذه الواجهة من خلال فئات مختلفة مخصصة لكل SGBD: فئة لـ SGBD MySQL، وأخرى لـ SGBD PostgreSQL… لتغيير SGBD، يتم تغيير برنامج التشغيل:

    يعزل برنامج التشغيل PDO البرنامج النصي PHP (1) عن SGBD (3، 6). ونظرًا لأن هذه برامج التشغيل تنفذ واجهة قياسية، فمن المتوقع ألا يتغير البرنامج النصي PHP (1) عند الانتقال من SGBD أو MySQL (3) إلى SGBD و PostgreSQL (6). لكن في الواقع، هذا الوضع المثالي غير موجود. ففي الواقع، للتواصل مع SGBD، يرسل البرنامج النصي PHP أوامر SQL (لغة الاستعلام القياسية). وهي لغة يتم تنفيذها من قبل جميع SGBD، لكنها غير مكتملة. ولذلك أضافت SGBD إليها أوامر خاصة بها. وهذا هو السبب الأول لعدم التوافق بين SGBD. بالإضافة إلى ذلك، قد تختلف أنواع البيانات القابلة للاستخدام في قواعد البيانات من SGBD إلى آخر. وبالتالي، فإن PostgreSQL يقبل عددًا من أنواع البيانات أكبر بكثير من SGBD وMySQL. وهذا هو السبب الثاني لعدم التوافق. سبب آخر هو إدارة المفاتيح الأولية التلقائية (التي يتم إنشاؤها بواسطة SGBD): تقريبًا كل SGBD له سياسته الخاصة. إلخ... أسباب عدم التوافق عديدة.

    إذا أردنا تجنب إعادة كتابة البرنامج النصي PHP (1) بالانتقال من MySQL (3) إلى PostgreSQL (6)، فإننا نضطر عادةً إلى إدراج طبقة جديدة بين البرنامج النصي PHP (1) وبرنامج التشغيل PDO (2، 5) والتي ستكون مهمتها إزالة حالات عدم التوافق بين البرنامجين النصيين SGBD. ومع ذلك، في الحالات البسيطة التي سنواجهها، لن تكون هذه الطبقة الإضافية ضرورية.

    سنستخدم الآن SGBD MySQL. وهو مضمن في حزمة Laragon (انظر الفقرة الرابط).

    إذا كان القارئ مبتدئًا في مجال قواعد البيانات ولغة SQL، فيمكنه قراءة الوثيقة [http://sergetahe.com/cours-tutoriels-de-programmation/cours-tutoriel-sql-avec-le-sgbd-firebird/]. يستخدم هذا المستند قاعدة بيانات Firebird SGBD وليس MySQL، ولكنه يقدم الأساسيات المتعلقة بقواعد البيانات ولغة SQL. وكما هو الحال مع MySQL، يتوفر لـ Firebird إصدار مجاني للاستخدام ولا يستهلك سوى مساحة صغيرة من الذاكرة.

    12.2. الاتصال بقاعدة بيانات MySQL

    يتم الاتصال بـ SGBD عن طريق إنشاء كائن PDO. يقبل المنشئ معلمات مختلفة:

    $dbh=new PDO(string $dsn,string $user,string $passwd,array $driver_options)

    معاني المعلمات هي كما يلي:

    $dsn
    (Data Source Name) هي سلسلة تحدد طبيعة SGBD وموقعه على الإنترنت. تشير السلسلة "mysql:host=localhost" إلى أننا نتعامل مع SGBD MySQL يعمل على الخادم المحلي. قد تتضمن هذه السلسلة معلمات أخرى، لا سيما منفذ الاستماع لـ SGBD واسم قاعدة البيانات التي نريد الاتصال بها: «mysql:host=localhost:port=3306:dbname=dbpersonnes»؛
    $user
    معرف المستخدم الذي يقوم بالاتصال؛
    $passwd
    كلمة مروره؛
    $driver_options
    مصفوفة خيارات لبرنامج تشغيل SGBD؛

    المعلمة الأولى هي الوحيدة الإلزامية. وسيكون الكائن الذي تم إنشاؤه بهذه الطريقة هو الداعم لجميع العمليات التي يتم إجراؤها على قاعدة البيانات التي تم الاتصال بها. إذا تعذر إنشاء الكائن PDO، يتم إصدار استثناء من النوع PDOException.

    فيما يلي مثال على اتصال [mysql-01.php]:

    
<?php

// الاتصال بقاعدة بيانات محلية MySql
// هوية المستخدم هي (admpersonnes، nobody)
const ID = "admpersonnes";
const PWD = "nobody";
const HOTE = "localhost";

try {
  // اتصال
  $dbh = new PDO("mysql:host=".HOTE, ID, PWD);
  print "Connexion réussie\n";
  // إغلاق الاتصال
  $dbh = NULL;
} catch (PDOException $e) {
  print "Erreur : " . $e->getMessage() . "\n";
  exit();
}

    12.3. إنشاء جدول

    يُظهر البرنامج النصي [mysql-02.php] إنشاء جدول في قاعدة بيانات:

    
<?php

// هوية قاعدة البيانات
const DSN = "mysql:host=localhost;dbname=dbpersonnes";
// بيانات اعتماد المستخدم
const ID = "admpersonnes";
const PWD = "nobody";

try {
  // الاتصال بقاعدة البيانات MySql
  $connexion = new PDO(DSN, ID, PWD);
  // حذف جدول «الأشخاص» إن وجد
  $sql = "drop table personnes";
  $connexion->exec($sql);
  // إنشاء جدول «الأشخاص»
  $sql = "create table personnes (prenom varchar(30) NOT NULL, nom varchar(30) NOT NULL, age integer NOT NULL, primary key(nom,prenom))";
  $connexion->exec($sql);
} catch (PDOException $ex) {
  // عرض الخطأ
  print "Erreur : " . $ex->getMessage() . "\n";
} finally {
  // يتم قطع الاتصال إذا لزم الأمر
  $connexion = NULL;
}
// النهاية
print "Terminé\n";
exit;

    تعليقات

    • السطر 11: الاتصال بقاعدة البيانات. هذا هو دائمًا أول ما يجب القيام به. نتيجة الاتصال هي كائن [PDO] الذي ستتم من خلاله العمليات على قاعدة البيانات؛
    • السطر 13: الأمر SQL [drop table personnes] سيحذف الجدول [personnes] من قاعدة البيانات [dbpersonnes]. إذا لم تكن الجدولة [personnes] موجودة، فلن يحدث خطأ؛
    • السطر 14: تنفيذ الأمر SQL السابق على قاعدة البيانات [dbpersonnes]. قد يؤدي هذا التنفيذ إلى تشغيل أمر [PDOException] الذي سيتم اعتراضه في السطر 18؛
    • السطر 16: هذا الأمر SQL ينشئ جدولًا باسم [personnes]. يحتوي الجدول على صفوف وأعمدة. تشكل الأعمدة ما يُعرف ببنية الجدول. أما الصفوف فتشكل محتوى الجدول. يمكن أن تحتوي قاعدة البيانات على جدول واحد أو أكثر. سيحتوي الجدول [personnes] هنا على ثلاثة أعمدة:
      • الاسم الأول: الاسم الأول للشخص على شكل سلسلة لا تتجاوز 30 حرفًا؛
      • اللقب: لقب الشخص نفسه على شكل سلسلة لا تتجاوز 30 حرفًا؛
      • العمر: عمر الشخص على شكل عدد صحيح؛
      • يفرض السمة NOT NULL على أحد الأعمدة أن يحتوي العمود على قيمة. وعدم تعيين قيمة له يؤدي إلى حدوث خطأ [PDOException]؛
      • يحدد [primary key(nom,prenom)] مفتاحًا أساسيًا للجدول [personnes]. يتمتع المفتاح الأساسي بقيمة فريدة لكل صف في الجدول. هنا، سيتم الحصول على المفتاح الأساسي عن طريق ربط العمودين [nom] و [prenom] في الصف. هذا القيد يعني أنه لا يمكن أن يوجد في الجدول شخصان يحملان نفس الاسم واللقب، أي شخصان متماثلان في الاسم. يؤدي إنشاء شخص يحمل نفس الاسم في الجدول إلى حدوث خطأ [PDOException]؛
    • السطر 17: تنفيذ الأمر SQL على قاعدة البيانات [dbpersonnes]؛
    • السطر 20: في حالة حدوث خطأ [PDOException]، يتم عرض رسالة الخطأ المرتبطة به؛
    • الأسطر 21-24: يتم الانتقال إلى الجملة [finally] في جميع الحالات، سواء حدث استثناء أم لا، لإغلاق الاتصال بقاعدة البيانات (السطر 23)؛

function exécuterCommandes(PDO $connexion, string $SQLFileName, bool $suivi = FALSE, bool $arrêt = TRUE): array {
// استخدام الاتصال $connexion
// تنفيذ الأوامر SQL الموجودة في الملف النصي SQLFileName
// هذا الملف هو ملف أوامر SQL يتم تنفيذها بمعدل أمر واحد في كل سطر
// إذا كان $suivi=1، فإن كل عملية تنفيذ لأمر SQL تُعرض مع إشارة إلى نجاحها أو فشلها
// إذا كانت قيمة $arrêt تساوي 1، تتوقف الدالة عند أول خطأ تصادفه، وإلا فإنها تنفذ جميع أوامر SQL
// تُرجع الدالة مصفوفة (عدد الأخطاء، الخطأ 1، الخطأ 2...)
// يتم التحقق من وجود الملف SQLFileName

  if (!file_exists($SQLFileName)) {
    return ["Le fichier [$SQLFileName] n'existe pas"];
  }

  // تنفيذ الاستعلامات SQL الموجودة في SQLFileName
  // يتم وضعها في مصفوفة
  $requêtes = file($SQLFileName);
  // خطأ؟
  if ($requêtes === FALSE) {
    return ["Erreur lors de l'exploitation du fichier SQL [$SQLFileName]"];
  }
  // يتم تنفيذ الاستعلامات واحدًا تلو الآخر - في البداية لا توجد أخطاء
  $erreurs = [];
  $i = 0;
  $fini = FALSE;
  while ($i < count($requêtes) && !$fini) {
    // نسترد نص الاستعلام
    // ستقوم وظيفة trim بإزالة علامة نهاية السطر
    $requête = trim($requêtes[$i]);
    // استعلام فارغ؟
    if (strlen($requête) == 0) {
      // يتم تجاهل الاستعلام والانتقال إلى الاستعلام التالي
      $i++;
      continue;
    }
    try {
      // تنفيذ الاستعلام - قد يتم إلقاء استثناء
      $connexion->exec($requête);
      // هل يتم عرض الشاشة أم لا؟
      if ($suivi) {
        print "$requête : Exécution réussie\n";
      }
    } catch (PDOException $ex) {
      // حدث خطأ
      addError($erreurs, $requête, $ex->getMessage(), $suivi);
      // هل نتوقف؟
      $fini = $arrêt;
    }
    // الاستعلام التالي
    $i++;
  }
  // النتيجة
  return $erreurs;
}

function addError(array &$erreurs, string $requête, string $msg, bool $suivi): void {
  // يتم إضافة رسالة خطأ
  $msg = "$requête : Erreur (" . $msg . ")";
  $erreurs[] = $msg;
  // متابعة الشاشة أم لا؟
  if ($suivi) {
    print "$msg\n";
  }

    نركز هنا على الأسطر من 16 إلى 24 التي تضيف شخصين إلى جدول الأشخاص في قاعدة البيانات [dbpersonnes].

    • السطر 21: يتم «إعداد» أمر SQL مع تحديد المعلمات. وتسبق المعلمات الرموز التالية: :اللقب، :الاسم الأول، :العمر. لـ«إعداد» أمر SQL، نستخدم الطريقة [PDO::prepare]. والنتيجة هي نوع [PDOStatement]. «الإعداد» ليس تنفيذًا: لا يتم تنفيذ أي شيء؛
    • السطر 23: تنفيذ الأمر «المُعد» باستخدام الطريقة [PDOStatement::execute]. للقيام بذلك، يجب تعيين قيم للمعلمات :الاسم، :الاسم الأول و:العمر. هناك عدة طرق للقيام بذلك. نستخدم هنا قاموسًا يحتوي على مفاتيح هي معلمات الأمر المُعد الذي نمرره إلى الطريقة [PDOStatement::execute]. هناك طريقة أخرى للقيام بذلك وهي إعطاء المعلمات قيمة باستخدام الطريقة [PDOStatement::bindValue($paramètre,$valeur)]. على سبيل المثال هنا: 
    
$statement→bindValue(“nom”,”Langevin”);
$statement→bindValue(“prenom”,”Paul”);
$statement→bindValue(“age”,47);
$statement→execute();

    العيب هو أنه يتعين تكرار هذه التعليمات لكل معلمة. لذا قد تكون طريقة القاموس أكثر عملية. الطريقة [PDOStatement::execute] تُنتج FALSE في حالة فشل التنفيذ؛

    • الطريقة المستخدمة هنا لإجراء الإدخالات:
      • طريقة مُعدة مسبقًا؛
      • n عمليات تنفيذ للأمر المُعد مسبقًا؛

    تكون أكثر توفيرًا لوقت التنفيذ مقارنة بتنفيذ n أوامر SQL مختلفة. لذا يُفضل استخدام هذه الطريقة. وهي قابلة للاستخدام مع أوامر SQL select و update و delete و insert. في حالة الأمر SQL select، بعد تنفيذه باستخدام [PDOStatement::execute]، يتم استرداد صفوف النتيجة باستخدام الطريقة [PDOStatement::fetchAll]؛

function exécuterCommandes(PDO $connexion, string $SQLFileName, bool $suivi = FALSE): array {
// استخدام الاتصال $connexion
// تنفيذ الأوامر SQL الموجودة في الملف النصي SQLFileName

// تُرجع الدالة مصفوفة (عدد الأخطاء، الخطأ 1، الخطأ 2…)
//
// يتم التحقق من وجود الملف SQLFileName
  if (!file_exists($SQLFileName)) {
    return ["Le fichier [$SQLFileName] n'existe pas"];
  }
  // تنفيذ الاستعلامات SQL الموجودة في SQLFileName
  // نضعها في جدول
  $requêtes = file($SQLFileName);
  // هل هناك خطأ؟
  if ($requêtes === FALSE) {
    return ["Erreur lors de l'exploitation du fichier SQL [$SQLFileName]"];
  }
  // سيتم وضع الاستعلامات في معاملة
  $connexion->beginTransaction();
  // يتم تنفيذ الاستعلامات واحدًا تلو الآخر - في البداية لا توجد أخطاء
  $erreurs = [];
  $i = 0;
  $fini = FALSE;
  while ($i < count($requêtes) && !$fini) {

    // ستقوم وظيفة trim بإزالة علامة نهاية السطر

    if (strlen($requête) == 0) {
      // يتم تجاهل الاستعلام والانتقال إلى الاستعلام التالي
      $i++;
      continue;

    // استرداد الاسم
    $commande = "";
    if (preg_match("/^\s*(\S+)/", $requête, $champs)) {
      $commande = strtolower($champs[0]);

    try {
      // هل هذا أمر SELECT؟
      if ($commande === "select") {

      } else {
        $résultat = $connexion->exec($requête);

      afficherInfos($commande, $résultat);

      $fini = TRUE;

  } else {

    // إضافة خطأ
    addError($erreurs, "", "Transaction annulée", $suivi);
  }
  // النتيجة
  return $erreurs;
}
