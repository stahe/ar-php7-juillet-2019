    7. الاستثناءات والأخطاء

    عندما تواجه إحدى طرق الفئة خطأً لا يمكن استرداده (ملف غير موجود، قاعدة بيانات غير متصلة، اتصال الشبكة معطل)، فإنها لا تعرض خطأً على وحدة التحكم (ملف، قاعدة بيانات) بل تطلق استثناءً. جميع الاستثناءات تمتد من الفئة [\Exception]. بالإضافة إلى الاستثناءات، يصدر التشغيل الداخلي لـ PHP أيضًا أخطاءً تكون فئتها الأساسية هي الفئة [\Error]. وتقوم كلتا الفئتين بتنفيذ واجهة PHP [\Throwable].

    تحدد PHP 7 عدة فئات من الاستثناءات:

    • في [1]، الاستثناءات المحددة مسبقًا في PHP؛

    7.4. الأخطاء المحددة مسبقًا في PHP 7

    تحدد PHP 7 عدة فئات من الأخطاء:

    فئة [\Error] هي الفئة الأم لجميع الأخطاء المحددة مسبقًا في PHP. تسمح فئة [ErrorException] بتغليف مثيل من فئة [\Error] داخل مثيل من فئة [\Exception]. وهذا يتيح توحيد إدارة الأخطاء من خلال معالجة الاستثناءات فقط.

    7.5. المثال 1

    يُظهر المثال الأول [exceptions-01.php] كلاً من أخطاء PHP واستثناءً:

    
<?php

// عرض جميع الأخطاء
ini_set("error_reporting", E_ALL);
ini_set("display_errors", "on");
// الرمز --------

// مفتاح غير معروف
print $var["abcd"];
// القسمة على الصفر

// جدول ذو حدود ثابتة

$array[1] = 2;
$array[4] = "foo";
// مؤشر خارج النطاق
$array[5]=8;

    7.6. معالجة الاستثناءات

    يوضح البرنامج النصي [exceptions-02.php] كيفية إدارة الاستثناءات:

    
<?php

// عرض جميع الأخطاء
ini_set("error_reporting", E_ALL);
ini_set("display_errors", "on");
// تحيط الكود بـ try / catch
try {
  $var = [];
  // مفتاح غير معروف
  print $var["abcd"];
  // القسمة على الصفر
  $var = 7 / 0;
  var_dump($var);
  // مصفوفة ذات حدود ثابتة
  $array = new \SplFixedArray(5);
  $array[1] = 2;
  $array[4] = "foo";
  // مؤشر خارج النطاق
  $array[5] = 8;
  // التحقق
  print "ce message ne sera pas affiché\n";
} catch (\Throwable $ex) {
  // \Throwable هي الواجهة التي تنفذها معظم الأخطاء والاستثناءات
  // يتم عرض الاستثناء
  print "erreur, message : " . $ex->getMessage() . ", type : " . get_class($ex) . "\n";
}

    تعليقات

    • هذا البرنامج النصي هو نفسه الذي تم عرضه في الفقرة السابقة. إلا أنه تم الآن إحاطة الكود الموجود في الأسطر 8-19، والذي قد يتسبب في حدوث أخطاء، ببنية try / catch: إذا تسبب الكود الموجود في الأسطر 8-21 في حدوث (إطلاق) استثناء أو خطأ، فسيتم معالجته بواسطة جملة catch الموجودة في الأسطر 22-26؛
    • السطر 22: المعلمة في جملة [catch] هي نوع الاستثناء أو الخطأ الذي نريد معالجته. عند تعيين النوع [\Throwable]، وهو واجهة، فإننا نشير إلى أننا نريد معالجة أي مثيل لفئة تنفذ واجهة [\Throwable]. ونظرًا لأن جميع فئات الأخطاء والاستثناءات تُنفِّذ هذه الواجهة، فإن الجملة [catch] تُعالج هنا أي خطأ/استثناء مُغلف في فئة؛
    • السطر 19: الأمر الذي يثير الخطأ ويؤدي إلى ظهور الاستثناء. بمجرد حدوث استثناء، يتم التحويل إلى الجملة [catch]. وبالتالي، لن يتم تنفيذ الكود الموجود بعد السطر 19؛

    7.7. معلمات البند [catch]

    دعونا نلقي نظرة على البرنامج النصي [exceptions-03.php] التالي:

    
<?php

// يتم عرض جميع الأخطاء
ini_set("error_reporting", E_ALL);
ini_set("display_errors", "on");

// مصفوفة ذات حدود ثابتة
$array = new \SplFixedArray(5);
try {
  // مؤشر خارج النطاق
  $array[5] = 8;
} catch (\Throwable $ex) {
  // عرض رسالة خطأ
  print "Erreur 1 : " . $ex->getMessage() . "\n";
}

try {
  // مؤشر خارج النطاق
  $array[5] = 8;
} catch (\Exception $ex) {
  // عرض رسالة خطأ
  print "Erreur 2 : " . $ex->getMessage() . "\n";
}

try {
  // مؤشر خارج النطاق
  $array[5] = 8;
} catch (\RuntimeException $ex) {
  // عرض رسالة خطأ
  print "Erreur 3 : " . $ex->getMessage() . "\n";
}

  // القسمة على 0
  intdiv(5, 0);
} catch (\Throwable $ex) {
  // عرض رسالة خطأ
  print "Erreur 4 : " . $ex->getMessage() . "\n";
}

try {
  // القسمة على 0
  intdiv(5, 0);
} catch (\DivisionByzeroError $ex) {
  // عرض رسالة خطأ
  print "Erreur 5 : " . $ex->getMessage() . "\n";
}

try {
  // القسمة على 0
  intdiv(5, 0);
} catch (\Error $ex) {
  // عرض رسالة خطأ
  print "Erreur 6 : " . $ex->getMessage() . "\n";
}

try {
  // القسمة على 0
  intdiv(5, 0);
} catch (\Exception $ex) {
  // عرض رسالة خطأ
  print "Erreur 6 : " . $ex->getMessage() . "\n";
}

      • السطر 12: يعالج خطأً من النوع [\Throwable]. وهذا صحيح لأن النوع [RuntimeException] مشتق من النوع [\Exception] الذي ينفذ الواجهة [\Throwable]؛
      • السطر 20: يعالج خطأً من النوع [\Exception]. وهذا صحيح لأن النوع [RuntimeException] مشتق من النوع [\Exception]؛
      • السطر 28: يعالج خطأً من النوع [\RuntimeException]. هذه هي الطريقة المفضلة لأنها تمثل النوع الدقيق للاستثناء الذي تم إنشاؤه؛

    7.8. البند [finally]

    يمكن أن تحتوي بنية try / catch على عنصر ثالث وتصبح بنية try / catch / finally. يتم تنفيذ كود الجملة [finally] في الحالتين التاليتين:

    • لا تطلق الجملة [try] استثناءً. يتم عندئذٍ تنفيذها بالكامل ثم ينتقل تنفيذ الكود إلى الجملة [finally] التي يتم تنفيذها بالكامل؛
    • تُطلق الجملة [try] استثناءً. وعندئذٍ يتم تنفيذها حتى الوصول إلى التعليمات التي تطلق الاستثناء. ثم ينتقل تنفيذ الكود إلى الجملة [catch] التي يتم تنفيذها بالكامل. ثم ينتقل تنفيذ الكود إلى الجملة [finally] التي يتم تنفيذها بالكامل؛

    وأخيرًا، يتم تنفيذ كود الجملة [finally] دائمًا. هذا السيناريو مفيد في الحالة التالية:

    • في الجملة [try]، حصل الكود على موارد (ملفات، قواعد بيانات، اتصالات شبكة، قوائم انتظار). وعادةً ما تستهلك هذه الموارد قدرًا كبيرًا من الذاكرة. لذا يجب إرجاعها (يُشار إليها غالبًا بـ«إغلاقها») في أقرب وقت ممكن؛
    • إذا تم الحصول على الموارد في السيناريو [try]، فسيتم إرجاعها في السيناريو [finally]. وهذا يضمن لنا أنه في جميع الحالات (سواء حدث خطأ أم لا)، يتم إرجاع الموارد التي تم الحصول عليها إلى النظام؛

    يوضح لنا البرنامج النصي التالي [exemples/exceptions/exceptions-04.php] كيفية عمل الجملة [finally] في حالات مختلفة:

    
<?php

// أو ينشئ مثيل استثناء
$e = new \Exception("Erreur…");    
var_dump($e);

// الاختبار الأول
try {
  print "Premier test\n";
  throw $e;
} catch (\Exception $ex1) {
  print $ex1->getMessage() . "\n";
} finally {
  print "Terminé\n";
}

// الاختبار الثاني
try {
  print "Second test\n";
} catch (\Exception $ex1) {
  print $ex1->getMessage() . "\n";
} finally {
  print "Terminé\n";
}

// الاختبار الثالث
try {
  print "Troisième test\n";
  return;
} catch (\Exception $ex1) {
  print $ex1->getMessage() . "\n";
} finally {
  print "Terminé\n";
}

    • السطر 11: يتم اعتراض الاستثناء [\Exception] وتُكتب رسالة الخطأ الخاصة به على وحدة التحكم؛

    7.9. إنشاء فئات الاستثناءات الخاصة

    في أي مشروع ذي حجم معقول، من المفيد التمييز بين الأخطاء المختلفة عن طريق تجميعها في فئات استثناءات مختلفة. في البرنامج النصي السابق، رأينا أن أي استثناء يمكن اعتراضه بواسطة جملة [catch (\Throwable]. يُنصح بذلك إذا لم تكن لدينا أي فكرة عن الاستثناء الذي تم اعتراضه وكانت معالجته هي نفسها لجميع الأخطاء. قد يكون هذا هو الحال أحيانًا، لكننا غالبًا ما نحتاج إلى تكييف المعالجة وفقًا لنوع الخطأ المحدد. لذا، يجب التمييز بين الأخطاء المختلفة.

    لنلقِ نظرة على البرنامج النصي [exceptions-06.php] التالي:

    
<?php

// نقوم بتعريف مجموعة الاستثناءات الخاصة بنا
class Exception1 extends \RuntimeException {
  
}

class Exception2 extends \RuntimeException {
  
}

// أو نستخدم استثناءاتنا
$e1 = new Exception1("Erreur1…");
var_dump($e1);
$e2 = new Exception2("Erreur2…");
var_dump($e2);

// الاختبار الأول
print ("premier test\n");
try {
  // نقوم بإطلاق استثناء من النوع Exception1
  throw $e1;
} catch (Exception1 $ex1) {
  print "Exception 1" . "\n";
  print $ex1->getMessage() . "\n";
} catch (Exception2 $ex2) {
  print "Exception 2" . "\n";
  print $ex2->getMessage() . "\n";
}

// الاختبار الثاني
print ("second test\n");
try {
  // نقوم بإطلاق استثناء من النوع Exception2
  throw $e2;
} catch (Exception1 $ex1) {
  print "Exception 1" . "\n";
  print $ex1->getMessage() . "\n";
} catch (Exception2 $ex2) {
  print "Exception 2" . "\n";
  print $ex2->getMessage() . "\n";
}

print ("troisième test\n");
try {
  // يتم إلقاء استثناء من النوع Exception1
  throw $e1;
} catch (Exception1 | Exception2 $ex) {
  print "Exception 1 ou 2" . "\n";
  print $ex->getMessage() . "\n";
}

    7.10. إعادة إطلاق استثناء

    يمكن إطلاق استثناء عدة مرات كما يوضح البرنامج النصي [exceptions-07.php] التالي:

    
<?php

try {
  try {
    // يتم إلقاء استثناء
    throw new \Exception("test");
  } catch (\Exception $ex) {
    // إعادة إطلاق الاستثناء الذي تم اعتراضه
    throw $ex;
  } finally {
    // سننتقل إلى finally
    print "finally 1\n";
  }
} catch (\Exception $ex2) {
  // يتم استرداد الاستثناء الأولي بنجاح
  print $ex2->getMessage() . " dans try / catch / finally externe\n";
} finally {
  // سننتقل بالفعل إلى جملة finally
  print "finally 2\n";
}
