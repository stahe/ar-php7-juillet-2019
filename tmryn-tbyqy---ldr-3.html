    تعليقات

    • الأسطر 6-20: السمات التي ستستوعب السمات التي تحمل نفس الاسم في الملف jSON و[taxadmindata.json]. هذه نقطة مهمة: سمات الفئة [TaxAdminData] مطابقة لتلك الموجودة في الملفين jSON و[taxadmindata.json]. هذه الميزة تسهل كتابة الكود بشكل كبير؛
    • لا تحتوي الفئة [TaxAdminData] على منشئ. وفي PHP، لا يمكن وجود أكثر من منشئ واحد. لذا فإن تحديد منشئ واحد يمنع تهيئة الكائن بطريقة أخرى. في ما يلي، لن تحتوي فئاتنا على منشئ، بل على عدة طرق من النوع [setFromQqChose] تسمح بتهيئتها بطرق مختلفة. يتم إنشاء كائن من النوع [TaxAdminData] باستخدام التعبير: 
    (new TaxAdminData())→setFromQqChose(…)
    • السطر 23: تقوم الطريقة [setFromJsonFile] بتهيئة سمات الفئة باستخدام السمات التي تحمل نفس الاسم في الملف [$jsonFilename]؛
    • الأسطر 24-42: يتم استخدام الملف jSON لإنشاء المصفوفة الترابطية [$arrayTaxAdminData]. وقد سبق أن صادفنا هذا الكود في البرنامج النصي [main.php] من الإصدار 02؛
    • الأسطر 44-47: في حالة حدوث خطأ أثناء معالجة الملف jSON، يتم إثارة استثناء. وسيتم تمرير هذا الاستثناء إلى البرنامج النصي الرئيسي [main.php]؛
    • الأسطر 48-51: يتم تهيئة سمات الفئة. ونستفيد هنا من حقيقة أن المصفوفة الترابطية [$arrayTaxAdminData] والفئة [TaxAdminData] لهما سمات تحمل نفس أسماء القيم الواردة من الملف jSON؛
    • الأسطر 53-57: يتم التحقق من أن جميع سمات الفئة [TaxAdminData] قد تم تهيئتها؛
    • السطر 53: يُرجع التعبير [get_object_vars($this)] مصفوفة مرتبطة تحتوي على سمات الكائن [$this]، وبالتالي سمات الفئة [TaxAdminData]. هنا يجب أن نفهم أن عملية التهيئة في الأسطر 48-51 قد أضافت سمات إلى الكائن [$this]. وبالتالي، إذا كتبنا: 
        $this->x = "1000";

    فسيتم إضافة السمة [x] إلى الكائن [$this] حتى لو لم يتم إعلان هذه السمة في الفئة [TaxAdminData]. ما هو مؤكد هو أن سمات الأسطر 6-20 هي بالفعل جزء من الكائن [$this]، ولكن ربما لم يتم تهيئتها. هذا خطأ يسهل الوقوع فيه، يكفي أن تخطئ في اسم سمة في الملف [taxadmindata.json]؛

    • الأسطر 54-57: يتم استعراض جميع سمات [$this]، وإذا لم يتم تهيئة إحداها، يتم إثارة استثناء؛
    • يمكن تهيئة سمة بقيمة غير صحيحة. في PHP، لا يمكن تحديد نوع للسمات. وبالتالي فإن العملية: 
    $this→plafondQfDemiPart=’abcd’

    ممكنة، في حين أن السمة [$plafondQfDemiPart] يجب أن تكون عددًا حقيقيًّا؛

    • الأسطر 59-71: يتم التحقق من أن كل سمة من سمات الفئة لها قيمة عددية حقيقية موجبة أو صفرية. وتقوم الدالة [check] في السطر 76 بهذه المهمة. والمعلمة الخاصة بها [$value] هي إما قيمة واحدة أو مصفوفة من القيم؛
    • السطر 62: تُرجع الدالة [check] كائنًا من النوع [\stdClass] مع سمتين:
      • [erreur]: تساوي TRUE في حالة حدوث خطأ، وتساوي FALSE في حالة عدم وجود خطأ؛
      • [value]: القيمة العددية الفعلية المطابقة للمعلمة [$value] التي تم تمريرها كمعلمة، السطر 62؛
    • السطر 64: يتم التحقق مما إذا كانت عملية التحقق قد نجحت أم لا؛
    • السطر 66: إذا لم يكن أحد السمات عددًا حقيقيًا موجبًا أو صفرًا، يتم إثارة استثناء؛
    • السطر 69: وإلا، يتم تسجيل قيمته العددية؛
    • السطر 73: يتم إرجاع الكائن [$this] كنتيجة؛

    الدالة [check] هي كما يلي:

    
private function check($value): \stdClass {
    // $value هو إما مصفوفة من العناصر أو عنصر واحد
    // يتم إنشاء مصفوفة
    if (!\is_array($value)) {
      $tableau = [$value];
    } else {
      $tableau = $value;
    }
    // يتم تحويل المصفوفة التي تحتوي على عناصر من نوع غير معروف إلى مصفوفة من الأعداد الحقيقية
    $newTableau = [];
    $result = new \stdClass();
    // يجب أن تكون عناصر المصفوفة أعدادًا عشرية موجبة أو صفرية
    $modèle = '/^\s*([+]?)\s*(\d+\.\d*|\.\d+|\d+)\s*$/';
    for ($i = 0; $i < count($tableau); $i ++) {
      if (preg_match($modèle, $tableau[$i])) {
        // نضع العدد العائم في newTableau
        $newTableau[] = (float) $tableau[$i];
      } else {
        // يتم تسجيل الخطأ
        $result->erreur = TRUE;
        // نخرج من البرنامج
        return $result;
      }
    }
    // نُرجع النتيجة
    $result->erreur = FALSE;
    if (!\is_array($value)) {
      // قيمة واحدة
      $result->value = $newTableau[0];
    } else {
      // قائمة من القيم
      $result->value = $newTableau;
    }
    return $result;
  }

    تعليقات

    • السطر 1: المعلمة [$value] هي إما مصفوفة أو عنصر واحد. كما أن نوعه غير معروف. تأتي القيمة من الملف [taxadmindata.json]. وفقًا للقيم المسجلة في هذا الملف، يمكن أن تكون القيم المقروءة أعدادًا صحيحة أو أعدادًا حقيقية أو سلاسل أو قيمًا منطقية. على سبيل المثال: 
    
"plafondQfDemiPart": 1551,
"plafondQfDemiPart": 1551.78,
"plafondQfDemiPart": "1551",

    • الأسطر 4-8: يتم إنشاء مصفوفة استنادًا إلى المعلمة [$value] التي تم استلامها كمعلمة في السطر 1؛
    • السطر 10: المصفوفة التي سيتم ملؤها بأعداد حقيقية؛
    • السطر 11: ستكون النتيجة كائنًا من النوع [\stdClass]؛
    • السطر 13: تعبير علائقي لعدد حقيقي موجب أو صفر؛
    • الأسطر 14-24: نتحقق من أن جميع عناصر المصفوفة [$tableau] هي أعداد حقيقية موجبة أو صفرية، ونملأ المصفوفة [$newTableau] بهذه العناصر المحولة إلى النوع [float] (السطر 17)؛

    • السطر 32: القيمة التي تم إرجاعها [$result→value] هي مصفوفة من الأعداد الحقيقية [float] أو عدد حقيقي واحد؛

    والنتيجة التي تم الحصول عليها هي كما يلي:

    تنتهي كل دالة تعيين بعملية [return $this]. وهذا يسمح بتهيئة السمات على النحو التالي:

    $data→setLimites($limites)→setCoeffR($coeffR)→setCoeffN($coeffN) ;

    في الواقع، قيمة [$data→setLimites($limites)] (السطر 32 من الكود) هي [$this]، وبالتالي فهي هنا [$data]. وبالتالي، يمكن استدعاء الطريقة [setCoeffR($coeffR)] لهذا الكائن وهكذا دواليك، لأن هذه الطريقة بدورها تُنتج أيضًا [$this] (السطر 37 من الكود). يُطلق على أسلوب كتابة طرق الفئة هذا، الذي يجعل الطرق التي لا يُفترض أن تُرجع أي قيمة تُرجع الكائن [$this]، اسم «الكتابة المتدفقة». وهو يسهل استخدام هذه الطرق.

    8.5. الفئة [Utilitaires]

    كما نحدد فئة [Utilitaires] في ملف [Utilitaires.php]:

    
<?php

// مساحة الأسماء
namespace Application;

// فئة من الدوال المساعدة
abstract class Utilitaires {

  public static function cutNewLinechar(string $ligne): string {
    // يتم حذف علامة نهاية السطر من $ligne إذا كانت موجودة
    $longueur = strlen($ligne);  // طول السطر
    while (substr($ligne, $longueur - 1, 1) == "\n" or substr($ligne, $longueur - 1, 1) == "\r") {
      $ligne = substr($ligne, 0, $longueur - 1);
      $longueur--;
    }
    // النهاية - إعادة السطر
    return($ligne);
  }
}

    // قد تحدث أخطاء كثيرة عند إدارة الملفات
    try {
      // أخطاء في فتح الملف
      $errors = fopen($errorsFileName, "w");
      if (!$errors) {
        throw new ExceptionImpots("Impossible de créer le fichier des erreurs [$errorsFileName]", 10);
      }
      // فتح ملف النتائج
      $results = fopen($resultsFileName, "w");
      if (!$results) {
        throw new ExceptionImpots("Impossible de créer le fichier des résultats [$resultsFileName]", 11);
      }
      // قراءة بيانات المستخدم
      // كل سطر يتكون من الحالة الاجتماعية، وعدد الأطفال، والراتب السنوي
      $data = fopen($usersFileName, "r");
      if (!$data) {
        throw new ExceptionImpots("Impossible d'ouvrir en lecture les déclarations des contribuables [$usersFileName]", 12);
      }
      // يتم معالجة السطر الحالي من ملف بيانات المستخدم
      // الذي يتخذ الشكل التالي: الحالة الاجتماعية، عدد الأبناء، الراتب السنوي
      $num = 1;         // رقم السطر الحالي
      $nbErreurs = 0;   // عدد الأخطاء التي تمت مواجهتها
      while ($ligne = fgets($data, 100)) {
        // تصحيح الأخطاء
        //  print "السطر رقم " . ($i + 1) . " : " . $ligne;

        $ligne = Utilitaires::cutNewLineChar($ligne);

        // يتم التحقق منها
        // يجب أن تكون الحالة الاجتماعية «نعم» أو «لا»
        $marié = trim(strtolower($marié));
        $erreur = ($marié !== "oui" and $marié !== "non");
        if (!$erreur) {
          // يجب أن يكون عدد الأطفال عددًا صحيحًا
          $enfants = trim($enfants);
          if (!preg_match("/^\s*\d+\s*$/", $enfants)) {
            $erreur = TRUE;
          } else {
            $enfants = (int) $enfants;
          }
        }
        if (!$erreur) {
          // الراتب عدد صحيح بدون سنتات اليورو
          $salaire = trim($salaire);
          if (!preg_match("/^\s*\d+\s*$/", $salaire)) {
            $erreur = TRUE;
          } else {
            $salaire = (int) $salaire;
          }
        }
        // خطأ؟
        if ($erreur) {
          fputs($errors, "la ligne [$num] du fichier [$usersFileName] est erronée\n");
          $nbErreurs++;
        } else {
          // يتم حساب الضريبة
          $result = $this->calculerImpot($marié, (int) $enfants, (int) $salaire);
          // يتم تسجيل النتيجة في ملف النتائج
          $result = ["marié" => $marié, "enfants" => $enfants, "salaire" => $salaire] + $result;
          fputs($results, \json_encode($result, JSON_UNESCAPED_UNICODE) . "\n");
        }
        // السطر التالي
        $num++;
      }
      // أخطاء؟
      if ($nbErreurs > 0) {
        throw new ExceptionImpots("Il y a eu des erreurs", 15);
      }
    } catch (ExceptionImpots $ex) {
      // إعادة تشغيل الاستثناء
      throw $ex;
    } finally {

      fclose($results);

    • الأسطر 18-20: يتم إعطاء نص للطريقة [getTaxAdminData] التي لم تحددها الفئة الأصلية. هنا، يكفي جعل السمة [$this->taxAdminData] مهيأة بواسطة المنشئ؛

    8.8. البرنامج النصي [main.php]

    يتم استخدام هذه الفئات والواجهة بواسطة البرنامج النصي [main.php] التالي:

    
<?php

// الالتزام الصارم بأنواع المعلمات المعلنة للدوال
declare(strict_types = 1);

// مساحة الأسماء
namespace Application;

// تضمين الواجهة والفئات
require_once __DIR__ . '/InterfaceImpots.php';
require_once __DIR__ . "/TaxAdminData.php";
require_once __DIR__ . '/ExceptionImpots.php';
require_once __DIR__ . '/Utilitaires.php';
require_once __DIR__ . '/AbstractBaseImpots.php';
require_once __DIR__ . "/ImpotsWithTaxAdminDataInJsonFile.php";

// اختبار -----------------------------------------------------
// تعريف الثوابت
const TAXPAYERSDATA_FILENAME = "taxpayersdata.txt";
const RESULTS_FILENAME = "resultats.txt";
const ERRORS_FILENAME = "errors.txt";
const TAXADMINDATA_FILENAME = "taxadmindata.json";

try {
  // يتم إنشاء كائن ImpotsWithTaxAdminDataInJsonFile
  $impots = new ImpotsWithTaxAdminDataInJsonFile(TAXADMINDATA_FILENAME);
  // تنفيذ الدفعة الخاصة بالضرائب
  $impots->executeBatchImpots(TAXPAYERSDATA_FILENAME, RESULTS_FILENAME, ERRORS_FILENAME);
} catch (ExceptionImpots $ex) {
  // عرض الخطأ
  print $ex->getMessage() . "\n";
}
// النهاية
print "Terminé\n";
exit();

    • الأسطر 24-29: يتم إنشاء كائن [ImpotsWithTaxAdminDataInJsonFile] ومعالجة أي استثناء محتمل؛
